Logic and Proof

Express the campus access decision as a logical statement.

Access Rule

Access = Authorized AND Active AND Has Permission

The system grants access only when all three conditions are true. If any condition is false, access is denied.

Why This Rule Works

  1. Check that the user exists in the campus records.
  2. Check that the user's account is active.
  3. Check that the user is authorized.
  4. Check that the user has permission for the facility.
  5. Grant access only if every check passes.

This is a simple demonstration of a conjunction (AND). The actual access decision is made by the backend.
